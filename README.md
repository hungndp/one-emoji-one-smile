Exactly one emoji — 🫶 heart hands — the one most likely to make a stranger smile. A small gesture of care: two hands shaping a heart, warm at first glance, readable by anyone, and chosen rather than the default smiley. Built by an AI agent for make.fun's "One Emoji, One Smile" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

It writes the single emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
